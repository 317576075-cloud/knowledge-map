# knowledge-map · 快速学习新领域

> **English**: A skill that maps any unfamiliar domain before you start learning it. It verifies authoritative sources first, then draws the big picture — core modules, how they connect, what to learn first, what can wait. [See a live demo →](./demo.html)

高手学新东西，第一步不是"开始学"，而是先画地图。这个 skill 在你进入新领域时先做一件事：查证权威资料，帮你画出这个领域的整体地图——由哪几个模块组成、彼此什么关系、哪些必须先学、哪些可以放后。让接下来的每一步，你都知道自己在哪。适用学习任何领域（职场、专业、技能、爱好、人物、文化、兴趣等）。

## 它怎么触发

说「我想快速了解XX」「帮我拆解XX领域」「刚接触XX该从哪入手」就行。

## 它做什么

1. **先问用途**：你学这个领域干什么用，决定地图怎么切（同一个领域，不同用途是两张不同的图）
2. **检索权威来源**：经典书目、名校课程大纲、官方文档，至少3个独立来源——结构判断必须经检索核实，不凭模型记忆编
3. **拆解结构**：3-7个核心模块 + 模块关系（谁依赖谁、谁驱动谁），标注主干（必须先啃）vs 分支（可后置）
4. **提取关键概念**：每个主干模块3-5个概念，每个配一句大白话，禁止术语裸奔
5. **补全景盲区**：领域怎么演变来的、现在有哪些流派、怎么判断做得好不好
6. **交付**：对话中给出完整文字版地图（结构+概念+入门路径+对口书单），并生成一份单文件 HTML 可视化地图（双击可开、手机可读、零依赖）

## 演示

生成效果示例：人的元学习（学会学习）知识地图 —— [demo.html](./demo.html)，可直接在线访问。

## 边界

- 只画地图，不逐点讲课——深入单个概念请另开对话
- 地图是起点不是终点：画完带着地图进真实项目，卡住了回来补局部
- 不编造来源：检索后仍不确定的，明确标注「待验证」
